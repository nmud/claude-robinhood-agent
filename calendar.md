## Rules tied to this file (enforced in CLAUDE.md)
- No NEW entry within 2 trading days before that ticker's earnings, unless the
  logged thesis explicitly IS an event trade (then size ≤ half normal).
- On FOMC/CPI days: no new entries before the release.
- If a held position's earnings date is inside the next 5 sessions, the daily
  pass must explicitly decide: hold through (re-affirm thesis in writing) or exit.
